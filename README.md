# Kanto Fiesta — Filipino Street Food Website

A lively, responsive, one-page Filipino street-food concept website. Built using **plain HTML, CSS, and JavaScript**—no frameworks, npm packages, build step, or server required.

## Features
- Mobile-friendly design and accessible collapsible mobile navigation
- Real Filipino street-food photography in the hero and menu
- Filterable street-food menu (fried, grilled, sweet)
- Opening hours and email contact link
- Fiesta-inspired red/yellow/cream theme and responsive typography

## Preview locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to its root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then `main` and `/ (root)`.
5. Save and wait for your published URL.

## Customize before launch
- Change the business name and brand text in `index.html`.
- Change menu descriptions and **sample prices** in the Menu section.
- Replace the **sample hours** in the Hours section.
- Replace `hello@kantofiesta.example` with your real email (both the link and notice).
- Replace or locally host the photos if you need offline image display.
